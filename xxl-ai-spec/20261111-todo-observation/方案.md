# 超级助理运行观测（todo）

日期：2026-11-11

## 一、需求相关
用户已确认实现前一轮方案。云版 todo 模块新增主页 Worker 动态、任务详情的请求流向、执行事件与只读历史回放；保留原有操作和基础色。图展示真实的 Trigger / Eval / Decision / Ticket / Assignment 关系，不虚构任务拆分。API 8080、UI 3000。

## 二、数据库设计
新增 xxl_ai_todo_event：thread_id、eval_id、ticket_id、assignment_id、round_id、call_id、kind、status、summary、detail、duration_ms、event_time 和公共时间字段。追加写入，thread + id 索引用于游标分页。业务事件和业务事务一起提交；同线程写事件前取线程锁保证提交顺序，运行时回调单独事务落库。新增 MySQL 增量脚本并同步 H2 初始化。历史任务保留关系图，没有采集的执行过程显示空状态。

## 三、菜单 / 授权
复用 todo:default。查询、事件流均校验当前用户和线程归属，主页仅返回当前用户的活动派工。无新菜单、上传或富文本。

## 四、后端改造
harness/superagent 通过回调上报模型及工具生命周期；todo 业务服务负责追加事件、脱敏、分页。增加 roundId 和 callId，保留每次报告。SSE 从持久化事件按游标读取，断线续传；连接关闭、超时释放任务。新增业务决定与 Router 建议分开展示。停止、恢复、重试均写事件。

## 五、前端改造
主页活动 Worker 卡片；详情扩大为自适应抽屉，默认展示运行观测，并保留原有时间线。可点击关系节点、按派工筛选事件、展开详情、只读回放。SSE 失败显示连接状态并自动重连；刷新补齐持久化事件。状态同时用图标和文字，键盘可操作，窄屏垂直排列；zh/en 同步。

待回填编译、SQL、工具封装、权限隔离、游标续传、前端交互和构建验证。

### 升级与使用
1. MySQL 现有部署：以 utf8mb4 连接执行 `doc/db/upgrade_20261111_todo_observation.sql`，再启动新版；仅新增事件表，不改已有任务。
2. H2 local profile：新旧库均自动处理，无须删除 `data`。
3. 进入“超级助理”，点击活动 Worker 卡片或待办行，默认打开“运行观测”。原有停止、重试、重新研判等操作保留于“经过”页签。
4. 已存在任务可展示关系图；升级前未采集的工具活动不能还原。首版保留追加事件，后续根据实际数据量制定保留/归档策略。
