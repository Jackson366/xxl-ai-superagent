# Skill 上传开发方案

## 需求

Web 管理端的「SKILL技能」提供「上传 Skill」入口。可选择单个 Markdown 文件或包含一个或多个技能目录的 ZIP。导入后可直接打开相应技能的内容管理页面。

## 数据库

沿用 `xxl_ai_skill` 与 `xxl_ai_skill_file`，技能和文件树在同一事务中写入。空间内同名时返回冲突提示。

## 菜单与权限

上传按钮和接口复用 `skill:default`，由服务端校验当前空间。

## 后端

`POST /skill/upload` 接收 multipart 文件。读取 `SKILL.md` 的 YAML 元数据，识别 ZIP 中的技能根目录，保存 UTF-8 文本及目录层级。文件树沿用现有固定节点。单个 Markdown 或包内单个文本文件上限为 2 MiB，ZIP 上传上限为 8 MiB，ZIP 内技能文本总量上限为 16 MiB。

## 前端

在 Skill 列表增加上传对话框，支持拖放、确认上传和查看导入结果。中英文文案成对维护。

## 验证

后端 Maven 编译、前端生产构建、类型检查及变更文件 ESLint 均通过。H2 联调验证了单文件、原有三技能 ZIP、文本内容、空间检查、同名冲突和异常归档。浏览器验证了无效文件提示、上传结果和内容管理跳转。
